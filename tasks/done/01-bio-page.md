# 01: Bio page

Build a single `index.html` page at the root of this folder with Jade's name, bio, and image.

## Content
- **Name:** Jade Nichols
- **Bio:** the text of `_source/Bio.txt`, word for word
- **Image:** `_source/cover-diagram.jpg`, the only image in `_source/`

## Requirements
- Plain HTML and CSS in one file: CSS in a `<style>` tag, no JavaScript, and no frameworks or external files other than the image.
- Copy the image to `assets/cover-diagram.jpg` and link to that copy. Leave the original in `_source/` unchanged.
- Give the image alt text that describes what it shows.

## Not in this task
The intro graphic, ABOUT and PROJECTS links, contact info, CV link, and projects page.

## Done when
- `index.html` shows the name, the full bio, and the image when opened in a browser.
- The image loads from `assets/`, and `_source/` stays out of Git.
- This file has moved to `tasks/done/`.
